# Privacy Policy

_Last updated: August 2026_

MetaColocationDemos ("the App") is a non-commercial demo application built for personal development and educational purposes, showcasing Meta Quest Mixed Reality Colocation features.

## What data is collected

To enable colocated multiplayer sessions, the App requests the following data through the Meta Horizon platform:

- **User ID** — used to identify players within a session and to share spatial anchors between colocated users, so that multiple headsets can align to the same physical space.
- **User profile (username and profile photo)** — used to display a player's name above their avatar during a shared session, so other players can identify who they are interacting with.

## How the data is used

This data is used exclusively at runtime to facilitate the colocated multiplayer experience: identifying players in a session, displaying their name tags, and sharing spatial anchors so that all participants see virtual content in the same real-world location. The data is not used for advertising, analytics, or any purpose beyond enabling this core functionality.

## Data storage and retention

The App does not operate its own backend server or persistent database. Player and session data exists only for the duration of an active multiplayer session (transmitted via Unity Gaming Services for networking, and Meta's Shared Spatial Anchor service for anchor alignment) and is not retained after the session ends.

## Third-party sharing

No data collected by the App is sold, shared, or disclosed to any third party. Data is only used within the App itself, between the colocated participants of a session.
